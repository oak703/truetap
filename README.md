# TrueTap

**Verify before you trust.**

TrueTap is a hackathon MVP by **NEXORA** for screening suspicious payment receipts, messages and links.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Push these files to the root of a GitHub repository and deploy `app.py` on Streamlit Community Cloud.

## Important limitation
A screenshot alone cannot prove that a payment was successfully settled. TrueTap is a fraud-screening and verification-assistance prototype. Merchants should confirm the transaction in their trusted banking/payment application before releasing goods.
